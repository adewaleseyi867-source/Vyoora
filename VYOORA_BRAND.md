# VYOORA Brand

## Colors

- Background: `#0A0A0F`
- Primary: `#7C3AED`
- Accent: `#D4FF3F`
- Text: White / `#A1A1AA`

## Logo

Use **OO** as the core logo idea:

- OO as two eyes: VYOORA sees the creator's content.
- OO as an infinity loop: **Create -> Publish -> Learn -> Create again**.
- OO as two circles: the creator and the audience.

## Color Rule

- New modules use this Midnight Creator system.
- Old modules stay with their existing layout and visual implementation for now.
- Do not redesign old modules when only adding new VYOORA modules or shared data.
